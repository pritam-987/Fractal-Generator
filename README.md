# Fractal-Generator

A simple Serpinski Triangle and Mandlebrot Set generator in Python and Pygame.

## Description

This is a simple interactive application in Pyhton to see some fractals. The project currently features Serpinski Triangle and Mandlebrot Set.Use left click to zoom the set.
- some resources used -
1.[chaos game](https://en.wikipedia.org/wiki/Sierpi%C5%84ski_triangle#Chaos_game)

## Getting Started

### Dependencies

- Windows 11

### Installing

- Go to the Release page.
- Download the .exe file and run it.

### Executing program

- How to run the program

1. install pygame
```
pip install pygame
```
2. clone the repo 
```
git clone https://github.com/pritam-987/Fractal-Generator/
cd Fractal-Generator
```
4. run the python file
```
python main.py
```
